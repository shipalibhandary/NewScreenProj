# NewScreenProj
NewScreenProj is a simple React Native mobile application that integrates two public APIs:
- Bored API – Suggests random activities when the user is bored
- Dictionary API – Provides word meanings and definitions
This project was built to practice API integration, React Native components, and mobile UI development.

## 🚀 Features
1. Bored API Integration
Fetches random activity suggestions
Displays:
- Activity name
- Type of activity
- Number of participants
- Helps users find something fun to do

2. Dictionary API Integration
- Allows users to enter any English word
- Fetches:
  - Word meaning
  - Definitions
- Displays results dynamically
